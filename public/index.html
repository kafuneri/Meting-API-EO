📖 MetingJS 配置说明

在前端网页引入 APlayer 与 MetingJS 之前，全局声明你的 EdgeOne API 地址：

APlayer + MetingJS HTML 示例 
<!-- 1. 声明自定义 Meting API 地址 -->
<script>
  var meting_api = window.location.origin + '/api?server=:server&type=:type&id=:id&auth=:auth&r=:r';
</script>

<!-- 2. 引入 APlayer 和 MetingJS -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/aplayer/dist/APlayer.min.css">
<script src="https://cdn.jsdelivr.net/npm/aplayer/dist/APlayer.min.js"></script>
<script src="https://cdn.jsdelivr.net/npm/meting@2.0.1/dist/Meting.min.js"></script>

<!-- 3. 页面中使用 -->
<meting-js server="netease" type="playlist" id="7326220405"></meting-js>

📋 支持参数与平台

参数名 默认值 可选值 说明
server netease netease, tencent, kugou, kuwo 音乐提供商
type playlist song, album, search, artist, playlist, lrc, url, pic 请求数据类型
id - 字符串 / 数字 歌曲 ID、歌单 ID 或搜索关键词
filter_vip 环境变量控制 (默认 true) true, false 无 Cookie 状态下是否过滤 VIP 试听音轨（设为 false 取消过滤）
